================

AudioWords is released for both iOS and Windows devices. Although they share the same name, they serve different purposes.


#### AudioWords(iOS) is a dictionary tool

It allows you to look up new words with their meanings read aloud via TTS, or add them to a named collection so you can review them later and solidify your understanding by listening. AudioWords can also be used as an ePub reader, enabling you to tap on any word to retrieve its meaning.

* [Install from App Store](https://apps.apple.com/us/app/audiowords/id1624921217)
* [App preview on YouTube](https://youtu.be/-Ymt75DUdQs)

#### AudioWords(Windows) is more of a vocabulary game to help you build your vocabulary.

It plays a word list (currently with a built-in TOEFL list and a junior list) and sample sentences for each word using a TTS engine, then waits for the user to spell the word. If the user spells it correctly, it will appear less frequently in the future; otherwise, it will appear more often. To make the process fun, it's designed like a grid-based 3D game.


* [Install from Microsoft Store](https://apps.microsoft.com/detail/9pl3ffmnz1mf?hl=en-US)
* [App preview on YouTube](https://youtu.be/VeFWkYwR1Pc)

# Privacy

AudioWords does not collect any data from user, all user data are stored on user's device and could be removed by user.
